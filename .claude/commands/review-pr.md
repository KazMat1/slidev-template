PR #$ARGUMENTS をレビューしてください。

## 手順
1. `gh pr view $ARGUMENTS` でPR情報を確認
2. `gh pr diff $ARGUMENTS` で差分を確認
3. CLAUDE.mdのガイドラインに照らしてレビュー
4. レビュー結果をまとめて報告

## レビュー観点
- Slidev 構文（フロントマター、レイアウト名、`---` 区切り、コードブロック言語指定）
- コンテンツ品質（1スライド=1メッセージ、7項目以下、3秒ルール）
- レイアウト多様性（同一レイアウト3枚連続禁止）
- UnoCSS スタイリング（インラインスタイル不可）
- コンポーネント利用（v-click, v-clicks の適切な使用）
- SDD 成果物の整合性（requirements.md, design.md との一貫性）
- セキュリティ（外部リソース参照、XSS リスク）
- TypeScript / Vue コンポーネントの型安全性

## レビュー結果フォーマット
- **概要**: PR全体の変更内容を1-2文で要約
- **問題点**: 重大度（Critical / Warning / Info）付きで列挙
- **改善提案**: 具体的な修正案
