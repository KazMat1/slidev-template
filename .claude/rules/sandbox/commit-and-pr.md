# コミットメッセージとプルリクエストの複数行対応

## ⚠️ 重要：Agent Skills を使用すること

複数行のコミットメッセージやプルリクエスト作成には、**必ず Agent Skills を使用してください**。

サンドボックスモードでは HEREDOC が使用できないため、以下の Agent Skills が用意されています：

| スキル名 | 用途 |
|---------|------|
| `commit-helper` | 複数行コミットメッセージでコミットを作成 |
| `pr-helper` | 複数行説明文でプルリクエストを作成 |

詳細な使用方法はスキルファイルを参照してください。
