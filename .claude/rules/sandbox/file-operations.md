# ファイル操作

## 専用ツールの使用を推奨

作業ディレクトリ内でのファイル・フォルダ操作は、Bashコマンドではなく専用ツールを使用すること：

| 操作 | ❌ 使用しない | ✅ 使用する | 理由 |
|------|-------------|-----------|------|
| ファイル作成 | `echo > file.txt` | Write ツール | サンドボックス制限を回避 |
| ファイル編集 | `sed`, `awk` | Edit ツール | 安全かつ確実 |
| ファイル読み取り | `cat`, `head`, `tail` | Read ツール | 権限問題を回避 |
| フォルダ作成 | `mkdir -p` | Write ツール（自動作成） | サンドボックスで動作 |

## 注意事項

- `mkdir`などのBashコマンドは、サンドボックスモードやOS権限の制限により失敗する場合があります
- Writeツールでファイルを作成すると、必要なフォルダが自動的に作成されます
- git コマンドなどの特殊な操作以外は、専用ツールを優先してください
